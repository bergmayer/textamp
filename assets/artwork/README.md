# Artwork placeholders

Lucide music-2, disc-3 and user-round from GPUI Kit Assets 0.9.0 match the graphical frontend's placeholder icons. The raster image places the glyph at 45% of its artwork canvas. PNG alpha supplies the shape; the active theme supplies foreground and background colors at runtime.

Regenerate the PNGs with `python3 assets/artwork/render.py` using ImageMagick. See LICENSE-LUCIDE for attribution.
